## 📝 Quy Chuẩn Ghi Chép Write-up HTB
Mỗi bài giải máy hoặc challenge trên HTB được lưu trữ theo cấu trúc:
1. **Reconnaissance:** Kết quả nmap, gobuster/ffuf, công nghệ phát hiện.
2. **Initial Foothold:** Cách tìm lỗ hổng entry-point và lấy được reverse shell.
3. **Privilege Escalation:** Leo thang đặc quyền lên user/root.
4. **Key Takeaways & Lessons Learned:** Những bài học và kỹ thuật mới rút ra được.
